# Dự Án Website Du Lịch
Đây là một **dự án cá nhân** nhằm tạo ra một website phục vụ cho nhu cầu *du lịch* cơ bản.
| Thư mục | Nội dung |
| du-lich-website | folder chính chứa dự án |
| back up | folder chứa các phần backup để lưu trữ |
| data | Nơi chứa dữ liệu gồm file excel |
| docs | nơi chứa nội dung gồm file Text document |
| logs | nơi chứa các hoạt động và tra lỗi |
| media | nơi chứa các file media như là logo |
Lệnh để liệt kê nội dung chi tiết của dự án:
```PowerShell
Get-ChildItem -Recurse -Force
```
